# Simulador de Inversión en Plazos Fijos 💰

Este es un proyecto académico desarrollado para la materia ANALISIS DE DATOS. Consiste en un programa en Java que analiza diferentes opciones de inversión en plazos fijos (Banco Provincia, Banco Nación e Banco Hipotecario) y recomienda la opción más rentable utilizando el interés compuesto.

## 🎯 Funcionalidades
- Carga de tasas históricas de los últimos 3 años.
- Cálculo de promedios de tasas por banco.
- Simulación de inversión interactiva (el usuario ingresa el monto).
- Evaluación de 3 modalidades: Anual, Trimestral y Mensual (con reinversión de ganancias).
- Validación de datos de entrada.
